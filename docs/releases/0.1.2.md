# Bree 0.1.2

An update to 0.1.1. Install it over the old app.

## Changes

- **Board (⌥⌘J).** A new button next to Wiki and Architecture opens the Board. It shows your agents by state: needs you, running, error and done. The Board only shows state. You answer an agent in its chat.
- **One color for one meaning.** The colors come from your terminal theme:
  - yellow means that an agent needs you;
  - red means an error or a risk;
  - green means done.

  A running agent has no color. Ivory marks the selection and unread items. With Increase Contrast on, signal colors reach 7:1.
- **English only.** Bree shows English menus and text on every system language.
- **Image strip removed.** The thumbnail bar under Claude's input box is gone. ⌘V and drag and drop send images straight to the terminal again, as in Claude Code without Bree.
- **Main window.**
  - The "+" and globe buttons stay in place.
  - The selected tab stays visible in a narrow pane.
  - The workspace context menu is shorter.
  - You can close the last workspace. Bree opens a fresh workspace in its place, so the window stays open.
  - The bell badge counts exactly the items in its list.
- **Bree name everywhere.** The app, the CLI, the settings and the state folders use only the Bree name.

## Notes

- The signature is ad hoc, so macOS may ask again for privacy permissions after you replace the app.

Install steps and known limits are the same as in [0.1.0](0.1.0.md).
