# Bree 0.1.0

First public release. Bree uses its own version numbers, starting here. The upstream cmux version in the Xcode project (`MARKETING_VERSION`) is not Bree's version.

## What Bree is

Bree is a local-only macOS terminal for running several coding agents in one window. It is a hard fork of [cmux](https://github.com/manaflow-ai/cmux) by Manaflow, Inc., which is built on [Ghostty](https://github.com/ghostty-org/ghostty). It keeps cmux's vertical tabs, split panes, notifications and scriptable socket/CLI. It does not track upstream.

Bree sends no telemetry, needs no account and does not update itself.

## Main features

- A dark-only look with a warm chrome palette derived from the terminal theme.
- Live agent cards in the sidebar and an Attention Center. A row says "Needs approval" when an agent waits for a permission and "Needs input" when it asks a question. Approval requests show a risk note when the pending command matches a risk rule, and you can snooze items.
- A command palette that groups commands (Workspace, Pane, Agent, View, Learn, App) and opens beside the sidebar, never over it.
- Turn review: open the diff of a finished agent turn and send review comments back to the agent.
- A bottom panel (Cmd-J) and a Quick View for HTML, CSV, JSONL and image folders.
- A Wiki popover (Option-Cmd-K) and an Architecture popover (Option-Cmd-A).
- A toast that shows what a socket client did to the UI (the remote-action toast).
- CLI for agents: `bree guide` (usage guide for agents), `bree queue`, `bree ask-human`, `bree agent explain` and `bree fork`.
- A shell editor, an image strip, pinned project files and keyboard focus regions.
- A resource guard that pauses hot panes.
- Its own identity: bundle id `com.bree.app`, state in `~/.bree` and `Application Support/Bree`, socket `bree.sock`. Bree runs next to cmux without sharing state.

## Removed from cmux

Cloud VMs, accounts and sign-in, Sparkle auto-update, telemetry, the GitHub PR poller, iPhone/mobile pairing, Mac-to-Mac devices, Hive, Canvas layout mode, the window-level Dock, the iOS simulator panel, agent-chat panels and vault checkpoints.

Kept: SSH (browser proxy, port forwarding, remote file preview, remote tmux), SSH-TUI, webhooks, Agent Inbox, Sessions and `bree fork`.

## Install

Download `Bree-0.1.0-arm64.zip` and `Bree-0.1.0-arm64.zip.sha256` from the release assets.

1. Check the download:
   ```bash
   shasum -a 256 -c Bree-0.1.0-arm64.zip.sha256
   ```
2. Unzip it and move `Bree.app` to `/Applications`.
3. The app is ad-hoc signed. It is not notarized, so Gatekeeper blocks the first launch. Do one of the following:
   - Control-click `Bree.app`, choose Open, then confirm.
   - Or open System Settings > Privacy & Security and choose Open Anyway after the first blocked launch.
   - Or remove the quarantine flag in a terminal:
     ```bash
     xattr -dr com.apple.quarantine /Applications/Bree.app
     ```
4. The command-line tool is `bree`. It is inside the app at `Bree.app/Contents/Resources/bin/bree`. To use it from any shell, link it onto your PATH:
   ```bash
   ln -s /Applications/Bree.app/Contents/Resources/bin/bree /usr/local/bin/bree
   ```

You can also build from source. See the README.

## Known limits

- Apple Silicon (arm64) only. There is no Intel or universal build.
- Requires macOS 14.0 or later (the project deployment target).
- No auto-update. To update, install a newer release over the old app.
- The signature is ad hoc, so macOS may ask again for privacy permissions (for example, folder access) after you replace the app with a new version.
- Bree is not notarized and is not affiliated with Manaflow or the Ghostty project.
