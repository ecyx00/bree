# Bree 0.1.1

A small update to 0.1.0. Install it over the old app.

## Changes

- **New tabs.** The "+" button now sits directly after the last tab and opens a terminal tab with one click. Right-click or long-press it to choose a terminal or a browser tab. A globe button next to it opens a browser tab. The right side of the tab bar keeps only the split buttons, Wiki and Architecture.
- **Branch name.** The tab bar no longer shows the branch. The label under each terminal shows the folder and the branch of that pane, for example `Projects/bree ⑂ main`.
- **Image strip.** The thumbnails of the images that you give to Claude now appear directly above Claude's input box. Hover a thumbnail and click ✕ to remove it. If the message is not sent yet, ✕ also removes `[Image #N]` from the prompt. Bree removes the token only when it finds it with certainty and never deletes other text. A click on a thumbnail opens a small preview instead of a full-window preview.
- **No tie to cmux.** Bree no longer reads, writes or shares anything that belongs to cmux:
  - It no longer copies `~/.config/cmux/cmux.json` on first launch.
  - It no longer reads `.cmux/` files in a project. It reads only `.bree/bree.json` and `.bree/dock.json`.
  - It no longer reads cmux's preferences.
  - On SSH hosts, Bree and SSH-TUI use `~/.bree`, not `~/.cmux`.

## Notes

- On an SSH host that you used with 0.1.0, Bree installs its remote helper again under `~/.bree` on the next connection. You can delete the old `~/.cmux` folder on that host if cmux does not use it.
- The signature is ad hoc, so macOS may ask again for privacy permissions after you replace the app.

Install steps and known limits are the same as in [0.1.0](0.1.0.md).
